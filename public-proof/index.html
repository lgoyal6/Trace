Credential-free public evaluation

Retrieval quality, including the result that got worse.

This page reads NeuLitTrace's checked-in held-out evaluation output. It exposes the local scorer's retrieval and grounding behavior without credentials, a model call, or a Snowflake account.

Boundary: these are reproducible local evaluation results over the checked-in corpus. This page is not a live Cortex Search deployment and is not medical guidance.
