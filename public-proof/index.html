Keep the result in scope

Each run creates and removes a temporary SQLite index. Queries execute the existing LocalVectorRetriever, including its 256-dimensional word and bigram feature hash and optional rarity multiplier. Citations include the hash of the exact source text.

The lexical evidence gate blocks matches caused only by feature-hash collisions. It is not calibrated answerability. Claim checks use lexical overlap and numeric containment, so a passing check does not establish factual or semantic correctness. No answer is generated, and no identity or private-corpus authorization is demonstrated.

The retained retrieval study includes adverse findings. Its results remain available separately and do not change when you run this playground.
